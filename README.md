# DECKS

Offline pitch decks for designathons — by COЯE.

Drop Figma exports, add text/link blocks, present fullscreen with local media preloaded.

## Share as `.core`

A `.core` file is a zip (`manifest.json` + `assets/` + `Present.html`). Open it in DECKS (double-click after install, or **Open .core** in the portable build) to edit.

### Present without DECKS

On any PC with a browser (no DECKS install):

1. Rename `deck.core` → `deck.zip`
2. Right‑click → **Extract All** (full extract — do not open files from Explorer’s zip preview)
3. Open `Present.html` from the extracted folder

That opens a present-only view (snaps / arrows / Space). No editing or reordering. Opening `Present.html` from inside the zip preview breaks images and video — always Extract All first.

## Develop


## Distribute (Windows)

```bash
npm run dist
```

Outputs in `release/`:

| Build | What it is |
|--------|------------|
| `DECKS-Setup-….exe` | Assisted installer — license, install dir, Start Menu + desktop shortcuts, `.core` association; uninstaller can optionally clear AppData |
| `DECKS-Portable-….exe` | **USB-friendly single .exe** — no install, no admin. Copy to a USB stick, run it, Open `.core` decks from the stick or anywhere |

Installer art, license, and NSIS pages live under `build/` (`installerSidebar.bmp`, `uninstallerSidebar.bmp`, `installerHeader.bmp`, `license.txt`, `installer.nsh`). Bitmaps are regenerated by `npm run icons`.

### Portable / USB workflow

1. Copy `DECKS-Portable-1.0.0.exe` (and your team’s `.core` files) onto a USB drive.
2. At the venue, plug in and double-click the portable exe — nothing installs on the machine.
3. **Open .core** → pick the deck → wait for **Ready** → **Present**.
4. Optional: put the portable app + decks in one folder so everything travels together.

The installer build is nicer for your own laptop (double-click `.core` files). Portable is for shared / locked-down designathon PCs.

| Key | Action |
|-----|--------|
| Ctrl+N | New board |
| Ctrl+O | Open `.core` |
| Ctrl+S | Save (flush autosave) |
| Ctrl+E | Export `.core` |
| F5 | Present |
| Esc | Exit present |
| Space / ↓ / → | Next snap |
| ↑ / ← | Prev snap |
